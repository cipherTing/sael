# Sael 运维控制台重构

更新日期：2026-09-25。本文记录已经在对话中确认并授权实施的方案。

## 产品与交互

- 一级入口：总览、场景、记录、接入、设置。总览以请求量、审查结果与审查性能为一体，共享时间轴和筛选，不再拆分业务/Jev 标签。
- 统一浅色中性界面、紧凑数据区域、中文字段、按需帮助；以 shadcn/ui 官方组件与 ECharts 为基础。
- 场景采用有序列表与编辑器，端点多选、精确模型列表、场景模板、原始分数、任一/全部、拦截/记录放行、复制、启停和拖拽排序。草稿可测试，保存后才影响线上。
- 测试支持真实文本分类、复用分数、完整匹配过程；测试不请求出站站点，不计入生产统计。
- 所有统计筛选与记录下钻共享时间、端点、模型、场景等上下文。
- 保留完整日期、倾斜轴标签、横向滚动；快捷时间立即应用，自定义起止点击应用。

## 运行边界

- 管理页面和管理 API 使用管理监听端口；业务请求使用独立进网监听端口。监听地址在启动配置中指定。
- 三个受监控端点：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。
- 其他业务路径透明转发；进网端口不提供管理 API 或管理页面，管理端口不转发业务请求。
- 出站使用一个 HTTP(S) 根地址，保留客户端路径、查询、认证头、请求和响应正文。
- 仅关注请求进入和 Jev 分类；不统计或记录上游响应错误。审查关闭时默认转发。
- 没有匹配场景的请求不生成逐条事件。Jev 错误与场景命中生成事件。

## 数据与可视化

- 核心指标：进网请求、完成审查、场景命中率、拦截率、Jev 失败率、审查耗时 P95。
- 请求按端点堆叠，命中率与拦截率折线，端点对比表，审查结果比例条，场景生效排行。
- 统一时间轴关联端点流量、场景比例、Jev 失败率和审查/Jev P50/P95；明细表同时包含流量、处理结果和耗时。热力图按需展开。
- 场景分析区分匹配、生效、匹配但被更高优先级场景决定；分数直方图涵盖所有成功审查请求。
- 耗时和分数以聚合分桶保存，不保存正常请求明细。分位数从分布计算，标明近似值，不伪造历史数据。
- 分母为零显示 —；查询失败与无数据是不同状态；数据按请求去重，场景匹配次数允许重叠。

## 2026-09-25 追加需求

- 模型限制属于每条场景：未指定为全部，指定后与端点范围共同约束；生产与草稿试算使用同一匹配逻辑。
- 模板列表展示名称与注释，选择后复制配置到当前编辑器，保留当前场景 ID 和优先级；配置独立编辑。
- 记录加入来源 IP、显式会话 ID、客户端请求 ID、User-Agent 和端点参数白名单；可按 IP、会话关联记录。
- 完整文本与预览统一在持久化前去敏，升级时清理历史文本。没有阈值的项与未超过阈值的项分组折叠，保留判定时阈值。
- 使用一个本地开发环境。移除旧版 8080 服务与独立演示环境，不将模拟统计混入开发数据库。
